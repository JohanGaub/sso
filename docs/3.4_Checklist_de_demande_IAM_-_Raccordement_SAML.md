# 3.4 Checklist de demande IAM - Raccordement SAML

Cette checklist sert à transmettre à l'équipe IAM toutes les informations nécessaires pour configurer un service SAML.

**Rappel vocabulaire :**

| Sigle | Signification |
| --- | --- |
| **SP** (Service Provider) | Notre application. |
| **IdP** (Identity Provider) | Plateforme IAM. |
| **ACS** (Assertion Consumer Service) | URL de retour vers l'application après authentification. |
| **SLO** (Single Logout) | Mécanisme de déconnexion SAML. |
