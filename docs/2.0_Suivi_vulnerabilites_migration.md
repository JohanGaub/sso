# 2. Suivi des vulnérabilités — Migration SSO

Micro-procédure commune aux guides **1.1**, **1.2** et **1.3**. Elle sert à mesurer les vulnérabilités **avant** et **après** la migration hors production via **Dependency Track**, puis à reporter les résultats dans l'Excel de suivi et le ticket Jira.

> [!NOTE]
> **Hors périmètre :** le détail du travail de migration SSO (claims, raccordement, bascule) reste dans le guide choisi. Cette page décrit uniquement l'**audit de sécurité**.

---

## 1. Prérequis

- Dépôt applicatif cloné en local, branche de travail créée (voir étape **1** du guide de migration).
- `cdxgen` disponible en local : `npm install -g @cyclonedx/cdxgen` (ou via la version fournie par l'outillage Eagles).
- **API key Dependency Track** : récupérée auprès du responsable de l'instance DT — ne jamais la committer dans le code ; la stocker en variable d'environnement ou dans un gestionnaire de secrets.
- **Identifiant du projet parent DT** : `058c651b-39ba-4072-875c-dadad580ec1d` (confirmer si l'instance a changé).
- Ticket Jira de la migration ouvert.
- Fichier de suivi Excel accessible (colonnes **Vulnérabilités avant migration** et **Vulnérabilités après migration**).

---

## 2. Quand lancer

| Moment | Quand (dans le guide) | Fichier généré |
| --- | --- | --- |
| **Avant** la migration | Phase **A — Préparer**, juste après la préparation du dépôt (étape 2) | `cdxgen-pre-migration-sbom.json` |
| **Après** la migration | Phase **D — Basculer**, juste après le PV de recette hors production | `cdxgen-post-migration-sbom.json` |

Un seul couple avant / après suffit pour le chantier hors production. Ne pas relancer l'audit à chaque environnement (pré-production / production), sauf demande explicite du responsable.

---

## 3. Commandes

Depuis la racine du dépôt applicatif. Remplacer `[API_KEY]` par la clé fournie par le responsable DT et `[NOM_DU_PROJET]` par le nom exact du projet applicatif.

### Avant migration

```bash
CDXGEN_DEBUG_MODE=DEBUG cdxgen \
  -o cdxgen-pre-migration-sbom.json \
  --server-url http://dependencytrack.dcv-place.cloud.stargate-pacy.enedis.fr \
  --api-key [API_KEY] \
  --parent-project-id 058c651b-39ba-4072-875c-dadad580ec1d \
  --project-name "[NOM_DU_PROJET] premigration" \
  --spec-version 1.6
```

Résultats :

- Fichier `cdxgen-pre-migration-sbom.json` créé localement (SBOM au format CycloneDX 1.6).
- Projet `[NOM_DU_PROJET] premigration` créé (ou mis à jour) dans Dependency Track via l'upload automatique.

### Après migration

```bash
CDXGEN_DEBUG_MODE=DEBUG cdxgen \
  -o cdxgen-post-migration-sbom.json \
  --server-url http://dependencytrack.dcv-place.cloud.stargate-pacy.enedis.fr \
  --api-key [API_KEY] \
  --parent-project-id 058c651b-39ba-4072-875c-dadad580ec1d \
  --project-name "[NOM_DU_PROJET] postmigration" \
  --spec-version 1.6
```

Résultats :

- Fichier `cdxgen-post-migration-sbom.json` créé localement.
- Projet `[NOM_DU_PROJET] postmigration` créé (ou mis à jour) dans Dependency Track.

---

## 4. Lire les métriques dans Dependency Track

Après chaque exécution, se connecter à [Dependency Track](http://dependencytrack.dcv-place.cloud.stargate-pacy.enedis.fr) et naviguer vers le projet correspondant (`premigration` ou `postmigration`).

| Métrique DT | Signification | À reporter dans Excel |
| --- | --- | --- |
| **Critical** | Vulnérabilités critiques (score CVSS ≥ 9,0) | ✅ Oui |
| **High** | Vulnérabilités hautes (CVSS 7,0–8,9) | ✅ Oui |
| **Medium** | Vulnérabilités moyennes (CVSS 4,0–6,9) | ✅ Oui |
| **Low / Info** | Faibles / informatifs | Optionnel |

Relever les métriques **Critical / High / Medium** pour le projet `premigration`, puis recommencer pour `postmigration`.

---

## 5. Reporting

1. Dans le fichier Excel de suivi, renseigner les colonnes :
   - **Vulnérabilités avant migration** : métriques Critical / High / Medium relevées dans le projet `premigration` de Dependency Track.
   - **Vulnérabilités après migration** : métriques relevées dans le projet `postmigration`.
2. Joindre les deux fichiers SBOM au ticket Jira de la migration :
   - `cdxgen-pre-migration-sbom.json`
   - `cdxgen-post-migration-sbom.json`
